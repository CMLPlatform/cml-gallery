R9lab is an open-source research platform for recording how durable products are built and how they come apart. Users break a product down into components and record materials, weight, dimensions, photographs and notes on recyclability, disassemblability and remanufacturability. The records are to be released as a citable dataset under CC BY 4.0.

It is built to turn the routine work of repairers, refurbishers and recyclers into primary data for industrial ecology and circular economy research, such as life cycle assessment and computer vision.

It combines a FastAPI backend, an Expo / React Native app for data collection, an Astro site for viewing project and dataset information, and a docs site.
