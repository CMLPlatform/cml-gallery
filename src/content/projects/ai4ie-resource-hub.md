Researchers who reach for AI methods in industrial ecology mostly start from the same few questions: which technique fits this problem, who has done it before, what runs locally, and how do I check the output. The hub collects answers in one place: a map of AI applications by field and technique, a reading list of more than 100 papers that filters by field, topic and technique and exports BibTeX or RIS, tooling and local-hardware guidance, verification checklists, and demos that run in the browser.

New papers come in through a weekly OpenAlex search that proposes leads for a person to read before anything is listed. The site is built with Astro and Starlight from Markdown and YAML files, so contributing means editing a file and opening a pull request. The code is MIT and the content CC BY 4.0. It is offered to the AI4IE working group and hosted from a personal account.
