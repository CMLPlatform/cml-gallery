RaMa-Scene is a Django web application for analysing Environmentally Extended Input-Output (EEIO) tables using EXIOBASE v3.3. It provides interactive visualisation and scenario modelling for circular economy analysis.

Credits from the repository's `contributors.txt`: back-end developer Sidney Niccolson (CML); front-end developer Bart Daniels (VITO); architecture by João Dias Rodrigues, Sidney Niccolson and Arjan de Koning (CML); IO calculations by Arjan de Koning (CML); project manager and modelling Franco Donati (CML).
